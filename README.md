# Focus Desk - Ambient Workspace & Digital Desk

An ambient digital workspace combining a Pomodoro focus timer, ambient soundscapes, to-do lists, and quick scratchpad notes.

## Features

- Integrated Pomodoro focus timer with Work, Short Break, and Long Break intervals
- Ambient background sound generators (Rain, Coffee Shop, White Noise, Ocean Waves) via Web Audio API
- Minimalist quick task manager with check-off functionality
- Sticky notes scratchpad for instant thoughts and meeting takeaways
- Full screen zen mode for distraction-free study and coding sessions
- Saves desk preferences and active tasks in browser LocalStorage

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Web Audio API
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/Focus-Desk.git
   cd Focus-Desk
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `index.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/index.html](http://localhost:8000/index.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for Focus Desk - Ambient Workspace & Digital Desk.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
